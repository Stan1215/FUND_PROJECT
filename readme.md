STEPS IN BUILDING THE PROJECT
1. Create a venv
2. Install requirements run "pip install -r requirements.txt" 
(Make sure you're running Python 3.12.9)

In creating the project
1. Create a branch first, then checkout that branch (e.g., git checkout -b gab/datatraining)
2. Before merging with main, do "git add ." then git commit -m "your message"
3. After finishing your work/code, run "git checkout main" then "git merge gab/datatraining"
